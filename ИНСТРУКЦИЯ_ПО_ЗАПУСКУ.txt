СОДЕРЖАНИЕ КОМПЛЕКТА:
1. ОТЧЕТ_ПРАКТИКА_САГАДИЕВ_ВАРИАНТ14_ПОЛИКЛИНИКА.docx
   - Полный пояснительный отчёт, строго оформленный по нормоконтролю колледжа 
     (ГОСТ и ЕСКД). Включает титульный лист, оглавление, инфологическую и 
     даталогическую модели, 8 таблиц, 9 скриншотов и диаграмм, все 8 запросов SQL, 
     описание форм, отчётов, макросов, системы безопасности и инструкцию администратора.

2. Создать_БД_Access_Автоматически.vbs
   - Готовый исполняемый скрипт для Windows. При двойном щелчке мыши он 
     автоматически через COM-объект MS Access создаёт полноценный файл 
     базы данных Polyclinic_Database.accdb с таблицами, связями, данными и запросами.

3. Модуль_Автоматизации_MS_Access.bas
   - Модуль Visual Basic for Applications (VBA) для СУБД MS Access.
     Инструкция по развёртыванию в MS Access:
     а) Откройте MS Access и создайте пустую базу данных (или откройте существующую).
     б) Нажмите комбинацию клавиш Alt + F11 (откроется редактор VBA).
     в) В верхнем меню выберите: File -> Import File... и выберите этот файл (.bas).
     г) Поставьте курсор внутрь процедуры Sub BuildPolyclinicDatabase() и нажмите F5.
     д) База данных автоматически создаст все 8 таблиц, настроит реляционные связи, 
        заполнит демо-данными и создаст все необходимые SQL-запросы!

4. Скрипт_Создания_БД_MS_Access.sql
   - Полный чистый SQL DDL-скрипт создания структуры БД: 8 таблиц со всеми первичными 
     и внешними ключами, уникальными ограничениями (UNIQUE), проверками (CHECK) 
     и каскадными обновлениями/удалениями.

5. Поликлиника_Исходные_Данные.xlsx
   - Таблица Excel, содержащая 8 листов с начальными данными по всем сущностям 
     поликлиники (Специальности, Врачи, Пациенты, Услуги, Диагнозы МКБ-10, 
     Расписание, Талоны, Назначения) для возможности стандартного импорта 
     через мастер MS Access (Внешние данные -> Excel).

6. Схемы_и_Иллюстрации/
   - Папка со всеми оригинальными схемами высокой четкости (ER-диаграмма, 
     схема связей Access, скриншоты форм, отчётов, диаграмм и архитектуры ролей).

ТРЕБОВАНИЯ ВАРИАНТА №14 (ВЫПОЛНЕНЫ В ПОЛНОМ ОБЪЕМЕ):
- 8 таблиц: Пациенты, Врачи, Специальности, Расписание приёма, Записи на приём, 
  Диагнозы, Назначения, Услуги.
- Запрос на свободные талоны к врачу по специальности на выбранную дату (qry_01).
- Параметрический запрос: история посещений пациента по ФИО (qry_02).
- Форма «Приём пациента» с выбором врача, пациента, автоматическим формированием 
  номера талона и подчинённой формой назначений.
- Отчёт «Загрузка врачей» по специальностям с количеством принятых пациентов.
- Бизнес-логика проверки: время приёма не может пересекаться у одного врача 
  (реализовано в модуле VBA CheckDoctorAppointmentConflict).
- Разграничение доступа: роли «Администратор» и «Пользователь».
